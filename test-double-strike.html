How to Purchase Double Strike

Step 1: Go to the Shop in the game
Step 2: Click on the "Skills" category button
Step 3: Find "Double Strike" in the skills list
Step 4: Click "Buy (300 coins)" button

Expected Behavior

✅ If you have 300+ coins: Double Strike should be purchasable
❌ If you have less than 300 coins: Button should show "Not enough coins"
✅ After purchase: Skill should appear in your inventory under Skills tab

Troubleshooting

If Double Strike doesn't appear:
  • Make sure you're in the "Skills" category (not Pilots, Bodies, etc.)
  • Check that you have 300+ coins
  • Try refreshing the page
  • Check the browser console for any errors
