How Double Strike Works

Function: performDoubleStrike()
Effect: Attacks twice in one turn with a 1-second delay between strikes
Requirements: Must have "Double Strike" in equippedSkills array
Compatibility: Works with Power-up bonus (1.5x damage multiplier)

Code Implementation

// New function added to game.js performDoubleStrike() { if (!this.currentBattle || this.currentBattle.turn !== 'player') return; // Check if player has Double Strike equipped if (!this.equippedSkills || !this.equippedSkills.includes('Double Strike')) { this.addBattleLogEntry(`Double Strike not equipped!`, 'battle-event'); return; } this.addBattleLogEntry(`DOUBLE STRIKE!`, 'special'); // First strike const firstDamage = Math.floor(this.currentBattle.player.attack * (0.8 + Math.random() * 0.4)); this.currentBattle.enemy.health = Math.max(0, this.currentBattle.enemy.health - firstDamage); this.addBattleLogEntry(`First strike deals ${firstDamage} damage!`, 'damage'); // Second strike after 1 second delay setTimeout(() => { const secondDamage = Math.floor(this.currentBattle.player.attack * (0.8 + Math.random() * 0.4)); this.currentBattle.enemy.health = Math.max(0, this.currentBattle.enemy.health - secondDamage); this.addBattleLogEntry(`Second strike deals ${secondDamage} damage!`, 'damage'); }, 1000); }

Dynamic Skill Button System

// New function added to game.js showEquippedSkills() { const battleControls = document.querySelector('.battle-controls'); if (!battleControls) return; // Remove existing dynamic skill buttons const existingDynamicButtons = battleControls.querySelectorAll('.dynamic-skill-btn'); existingDynamicButtons.forEach(btn => btn.remove()); // Show equipped skills as buttons if (this.equippedSkills && this.equippedSkills.length > 0) { this.equippedSkills.forEach(skillName => { // Skip skills that already have hardcoded buttons if (['Slash', 'Power-up', 'Defend', 'Dodge', 'Special', 'Bonkler Beam'].includes(skillName)) { return; } const skillButton = document.createElement('button'); skillButton.className = 'battle-btn dynamic-skill-btn'; skillButton.textContent = skillName; // Add click event listener skillButton.addEventListener('click', () => { if (skillName === 'Double Strike') { this.performDoubleStrike(); } }); battleControls.appendChild(skillButton); }); } }

Troubleshooting

If Double Strike doesn't appear in battle:
  • Make sure Double Strike is purchased from the shop
  • Make sure Double Strike is equipped in Inventory → Skills
  • Check that equippedSkills array contains "Double Strike"
  • Try refreshing the page and re-equipping the skill
